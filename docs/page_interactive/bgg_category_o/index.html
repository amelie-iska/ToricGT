Finite homological certificates

Toric BGG Category O

The Toric BGG layer is a finite certificate system: it never claims the model contains a literal abelian category. It attaches small sign-vector posets, standard-filtration masks, sparse differentials, Koszul degree profiles, Gale-dual labels, and derived signatures to training records. Late-phase weights remain small so BPB stays primary.

This page combines the hand-written method explainer with the generated Category O audit. If a metric is listed as unavailable, that does not mean the method is absent; it means the copied public run did not emit the exact finite certificate required to compute that metric. The late gate is intentionally conservative.

How It Affects Training

  • Weight up carefully: improves standard-object routing and homological consistency when records carry exact certificates.
  • Weight down early: prevents sparse certificate losses from dominating byte likelihood before BPB stabilizes.
  • Use as audit: unavailable exact metrics should trigger data/certificate instrumentation review, not a blind loss increase.
