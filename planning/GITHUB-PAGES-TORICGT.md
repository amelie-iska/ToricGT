# ToricGT GitHub Pages Plan

This task is a first-class deliverable for the ToricGT project site.
The page should present the project as a polished, dark-mode research and
competition artifact while staying grounded in the actual best-run metrics,
reports, screenshots, and code paths generated by the current training loop.

## Required Outputs

- Build a static GitHub Pages site in `docs/`.
- Use the best completed campaign run available in
  `training_notes/*/campaign_state.json`.
- Show BPB, loss, artifact size, graph/toric/topological/BGG metrics, and the
  active objective families.
- Include appealing diagrams and screenshots from `assets/` and `outputs/`.
- Include animated didactic visual helpers for:
  - tropical shortest-path / min-plus tokenization DAGs,
  - toric fan and one-dimensional cone structure,
  - graph/Forest-of-Thought branching and retrieval,
  - persistent-homology and vectorized-PH audit flow.
- Link to:
  - ToricGT codebase,
  - Hugging Face checkpoint repository,
  - OpenAI Parameter Golf competition page,
  - the submission pull request when available,
  - the longer ToricGT paper in `assets/`.
- Keep the page self-contained enough for GitHub Pages: all local images used
  by the page are copied into `docs/page_assets/`.
- Add a GitHub Pages workflow so the site can be deployed from the repository.

## Implementation Notes

- The page builder is `scripts/build_toricgt_pages.py`.
- The builder should be deterministic and safe to rerun after the final run,
  the 900-step candidate, Hugging Face upload, and Parameter Golf PR creation.
- If the Parameter Golf PR URL is not available yet, the page should render a
  clear "pending" state rather than pretending the PR exists.
- The current best completed run is expected to be the best exported
  `final_int8_zlib_roundtrip` BPB among completed campaign rows under the
  16,000,000-byte artifact cap. If later run 10 or the 900-step candidate wins,
  rerunning the builder will update the page.
